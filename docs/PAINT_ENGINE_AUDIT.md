# 塗膜エンジンの監査とGitHub統合

2026-10-05。ローカル版で光学、パレット、筆・保存のサブエージェント監査と修正を実施した後、GitHub Pages版へ統合した。GitHub版は既存のRIT由来38波長K/Sプロファイルを維持し、長押し、保存レシピの追加、タッチ操作、キャンバスの拡大・移動、チュートリアルを含む静的アプリとして検証する。

## 実装と検証対象

| 対象 | 実装 | 回帰検証 |
| --- | --- | --- |
| 光学 | 有限厚KMの反射・透過、Saunderson補正、38波長の順序付きグレーズ | ゼロ厚、吸収のみ、散乱のみ、極厚、分割した同一塗膜、独立した一般式との比較 |
| 表示 | 画像境界での分光再構成、全塗膜の積分後に色域写像、線形光での線画合成 | 高速経路と一般経路の最大1階調差、薄い色・微量顔料・色域境界 |
| 顔料の移動 | Cartesianセルで各材料を交換する手混ぜ、保有量が有限の筆、紙目への保存的輸送 | 折り返し・円・交差・端、筆圧・筆幅の変更、各顔料・水・bodyの総量 |
| 再利用 | 連続する顔料・水の量、光学厚み、塗膜の階層と照明を保存 | 乾いた多層色と不透明度を含むスポイト再描画、保存パレット再展開 |
| 乾燥・保存 | 実経過時間、乾層のbody、追加PNG平面、同期journal | pagehide、モード変更、未完了IDB、容量不足、Undo/Redo後の乾燥再開 |
| 既存機能 | 1タップ、長押し、波形の伸ばし、保存色、パン・ズーム、各種テンプレート | 静的ビルドのPC、Android、iPhone、iPhone SE |

原色スウォッチは実測プロファイルのマストーンと同じ値を表示する。整数の配合は概要であり、スポイトで再利用する際の正本は連続量と塗膜の構造。旧版1〜3のレシピJSONと旧PNG保存形式を引き続き読み込む。新しいレシピJSONは版4。

## 再現コマンド

```bash
npm ci --ignore-scripts
npm test
npm run test:e2e:static
node --import tsx tests/benchmark-paint.mjs --coloring --empty-layers
```

投入ダブのサイズと水の広い足跡で総量が増える不具合を追加監査で検出し、解析積分で正規化した。独立した1px数値積分の27条件（サイズ・形状・湿潤・水）では1単位の最大相対誤差8.77e-7。サイズ違いの1:1をすべて混ぜると赤50.0000883%、水と顔料の1:1では水50.0000142%となる。

旧WebGLのRGB照明・粒状模様と水色のscreenグラデーションによる再展開時の色差も除去した。WebGL・2D・ライブ描画・再展開は同じ分光塗膜の画素を表示する。

描画専用サンプラーを分離し、画素ごとの整数レシピ・Inspector物性計算を省いた。独立した4,000地点の比較では材料量・水分比・光学層の差0。実Chromium Canvas（1100×760、赤1＋水1）は初回845msから43ms、以後5回の中央値22.9ms・最大24msとなった。単色・希釈・薄膜端・重なり・長押しの5例はスポイトから再展開したRGB差0。修正後の光学サブエージェント監査はOK。

型・Lint・単体190件・静的HTML2件は通過。静的アプリのブラウザ検証はPC38件、Android12件、iPhone3件、iPhone SE3件の全56件を通過。WebKitが低レベルAndroidタッチプロトコルをサポートしない18件は設定どおり除外した。`npm ci --ignore-scripts --dry-run` でもlockfileの整合を確認した。READMEの8枚の画面画像を現行ビルドから更新した。

## 再現の範囲

係数は特定の完成絵の具に由来する。モデルの厚みは相対光学量であり、μmや実測グラムへ校正していない。乾燥速度・湿潤時の暗化・紙目・流動性も近似であり、銘柄、ロット、照明、下地を指定した実物との色差ゼロは主張しない。外部RGB画像の反射スペクトルも一意には決まらない。
